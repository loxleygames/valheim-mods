# Unburdened

Armour no longer slows you down.

Upgrading to iron shouldn't mean you can't run away from the thing iron was meant to protect you from. This removes the movement speed penalty from helmets, chests, legs and capes. Bonuses (the Fenris set) are untouched.

It's done at the item level, so run speed, jump and dodge stamina costs, and the tooltip all agree.

## Config

`BepInEx/config/games.loxley.unburdened.cfg`

| Setting | Default | |
|---|---|---|
| Armour | true | helmets, chests, legs, capes |
| Shields | false | tower shields carry a heavy one |
| Weapons | false | weapons and tools |
| Keep | 0 | fraction of the penalty to keep — 0.5 for half |

Client-side. Requires BepInEx only.
