# Inventory Reforged

Three things your inventory should have had. Built for playing with friends.

## Stash

Press **P** (or the **Stash** button on your inventory) and every item that a nearby chest already holds goes into that chest. Chests within 10m. Equipped gear, favourites and the hotbar stay put.

**Alt+click** an item to favourite it (★). Favourites are never stashed or place-stacked.

Each chest is asked through the game's own "Place stacks" request, so the chest's owner checks nobody has it open and hands it over before anything moves.

## Shared chests

Two players can have the same chest open at once. The second player sees the chest live and can take, put, move, place stacks, take all and eat from it. Under the hood every move they make is sent to the chest's owner, applied there, and only then reflected in their own inventory, so nothing is ever duplicated or lost to a race. **Everyone in the world needs the mod for this one.**

## Armour slots

A fifth inventory row with **Head / Chest / Legs / Cape** slots. Equip armour and it moves there; unequip and it comes back to the main grid. Drop the right piece on a slot to equip it. They're real inventory slots, so repair and durability work exactly as before. Weapons, shields and utility items are deliberately left alone.

Removing the mod later: unequip your armour first so it's back in the main grid.

## Config

`BepInEx/config/games.loxley.inventoryreforged.cfg` — stash key/range/hotbar rule, button position, each feature on/off, panel height for the armour row.

Requires BepInEx. No other dependencies.
