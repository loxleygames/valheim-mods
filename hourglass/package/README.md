# Hourglass

A buildable **Hourglass** (Hammer → Misc, 6 Fine wood + 4 Resin + 2 Greydwarf eyes at a Workbench).

Use it and the sun stops at noon for everyone in the world. Use it again and time flows on. No night, no night spawns, no fumbling for torches while you're laying out a great hall.

The world's calendar keeps counting underneath — days still pass, so nothing that runs on the world clock (crops, fermenters, raids) changes. Only the sky and the day/night state are held.

Works on any server without the server needing the mod. Players without the mod see normal time.

Config: `TimeOfDay` — 0.5 is noon, 0.25 dawn, 0.75 dusk.
