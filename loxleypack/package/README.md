# LoxleyPack

Every Loxley mod in one install. Built for playing Valheim with friends on the current version of the game.

| Mod | What it does |
|---|---|
| **Inventory Reforged** | Quick stack to nearby chests (working today), craft from chests, shared chests, armour slots |
| **Comfy Fishing** | No tug-of-war: craft a rod, click on the bite, it reels itself in. Rod tiers, bait tiers |
| **Gungnir** | Thrown spears return to your hand |
| **Trophy Pouch** | Trophies as a tally, not clutter. Free slots, not lost on death, crafting still sees them |
| **Moorings** | A post to tie your boat to. Moored boats can't be damaged |
| **Hourglass** | A buildable hourglass that holds the sun at noon while you build |
| **Unburdened** | Armour no longer slows you down |

Each mod has its own page with details and config. Nothing here changes vanilla recipes or costs.
