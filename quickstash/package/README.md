# QuickStash

Press **P** (or the **Stash** button on your inventory) and every item in your inventory that a nearby chest already holds goes into that chest. Chests within 10m, hotbar left alone, equipped gear left alone.

**Multiplayer-safe.** Each chest is asked through the game's own "Place stacks" request, so the chest's owner checks nobody has it open and hands it over before anything moves. Other players don't need the mod.

Config (`BepInEx/config/games.loxley.quickstash.cfg`): key, range, hotbar protection, player-built chests only, button on/off and position.

Requires BepInEx. No other dependencies.
